# Elisabeth von Thüringen

3D-Religions-Abenteuer für die 3. Klasse: Elisabeth läuft über eine Wiese zu 12 Stationen
und beantwortet dort Quizfragen zu ihrem Leben (Ungarn, Wartburg, Rosenwunder, Marburg, Elisabeth-Tag …).

Steuerung: Pfeiltasten / WASD, Klick bzw. Tippen auf die Wiese oder Steuerkreuz auf dem Handy.
